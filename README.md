# gas-co-monitor

A gas / CO monitor: a **Raspberry Pi Pico W** device plus an **iOS / watchOS** app with widgets.

| Directory | Contents |
|---|---|
| [`raspberry-pi/`](raspberry-pi/) | MicroPython: sensor readout (ADC), 20×4 LCD, BLE, push alerts via [ntfy](https://ntfy.sh), UDP broadcast of readings |
| [`ios/`](ios/) | GazCoMonitor app (SwiftUI, BLE): live readings, sensor picker, history, alarm notifications; iOS widget, Apple Watch app and widget; shared `GasCoKit` package |

## Raspberry Pi Pico W

```sh
cp raspberry-pi/config.example.py raspberry-pi/config.py   # Wi-Fi + ntfy topic/token; the file is git-ignored
```

Copy the files from `raspberry-pi/` to the Pico (e.g. `mpremote cp *.py :`).

## iOS

The project is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen): `cd ios && xcodegen && open GazCoMonitor.xcodeproj`.
App Store release materials (in Polish): [ios/Release/](ios/Release/).
